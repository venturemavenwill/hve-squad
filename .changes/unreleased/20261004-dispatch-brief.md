- **Dispatch brief replaces coordinator discovery turns.** New read-only `scripts/Get-SquadDispatchBrief.ps1` prints, in one call under the Copilot CLI's 20,480-byte inline output limit, what the coordinator used to find out one turn at a time: UTC time, next hand-off `turn`, federation and cost-ceiling status, ledger shape, the concurrency cap, the roster with each agent's model pin, rate row, tier, deliverable root, bounded pick and dispatchability (the Step 1b precheck), ready consumption objects from the dispatch-size estimator, the resolved `Write-SquadHandoff.ps1` command, and the verbatim Bounded Lane, Owner Finish Barrier and Script Hand-off sections. The coordinator runs it first; when its `coverage:` line covers the request it reads no reference, agent file or rate table, otherwise it reads the three references whole with `forceReadLargeFiles` (the CLI refuses whole files over 20 KB). Dispatches must name the roster agent as `agent_type`. The Script Hand-off section now carries the payload skeleton, background owners are awaited in one `read_agent` block, and ready workstream hand-offs run in one shell call. In paired live runs on the same three-item bounded task (Sonnet 5 coordinator), the median moved from 369 s / 101 credits on the previous version to 307 s / 67 credits, with 3 of 3 runs passing tests, review, script hand-off and ledger check.
